# Direction visuelle — éviter le look IA générique

Le builder TikTak donne des briques ; **toi** tu choisis une direction.
Le **plafond** esthétique passe souvent par le **HTML custom**
(`references/custom-html.md`, réf. Niglora) : direction de marque totale,
pas un empilement de sections démarrées par défaut.

Si on retire le logo et que la home pourrait être n'importe quelle boutique
Shopify, le branding est trop faible.

## Principes (home & thème)

1. **Une composition** au premier viewport — pas un dashboard.
2. **Marque d'abord** — nom / logo héros-level, pas seulement dans le header.
3. **Typographie expressive** — couple corps + titres cohérent avec la niche
   (tech ≠ beauté ≠ alimentaire). Éviter « Inter partout » si le catalogue
   offre mieux pour les titres.
4. **Atmosphère** — fond / surface / accent qui se parlent ; pas plat gris
   universel sans intention.
5. **Héros plein cadre** sur landing / home promo — image dominante edge-to-edge
   quand le template le permet ; pas de collage de petites cards.
6. **Budget héros** : marque, 1 headline, 1 phrase, 1 groupe CTA, 1 visuel.
7. **Une job / section.**
8. **Motion** : 2–3 mouvements utiles max (pas de confettis).

## À éviter (biais IA courants)

- Violet / indigo gradient sur blanc
- Fond crème + serif + terracotta « poster »
- Layout journal (filets, zéro radius, colonnes denses)
- Dark mode forcé sans demande
- Glow, pills partout, ombres multi-couches, emojis décoratifs
- Stats strips + badges flottants sur le héros

## Niche → signal

| Niche | Signaux |
|-------|---------|
| High-tech | Contraste net, navy/bleu, accent vif (orange/cyan), grilles denses, recherche visible |
| Mode | Espace négatif, éditorial, photo produit large, typo display |
| Beauté | Soft, surfaces claires, accents métalliques discrets, focus texture |
| Maison | Tons terre / sauge, matière, photos ambiance |
| Food | Chaud, appétence, pastilles catégories, CTA achat rapide |

## Cohérence boutons

Après palette : décider **une** hiérarchie :
- Primary = conversion (acheter / ajouter)
- Secondary = outline / ghost
- Exception locale OK (ex. CTA héros accent, reste navy) — documenter le choix

## Validation visuelle

Toujours finir par captures **desktop 1440** + **mobile 390** des zones :
héros, une rangée produits, header sticky, une fiche produit.
Corriger si contraste faible, texte coupé, carousel non demandé, ou CTA
hors palette.
